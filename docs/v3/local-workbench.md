# V3 ローカルワークベンチ

V2 `3b4bb10` から独立した `v3/local-team-workbench`。AWSへの適用とモデル送信は行わない。公式Claude Codeの起動・入力・ログイン・権限と工程の承認は本人が行う。

## 開発起動

Node 24以上、Bun 1.3.14、本人がインストールした公式Claude Codeを利用する。

```sh
bun install --frozen-lockfile --ignore-scripts
cd apps/desktop
./node_modules/.bin/install-electron
./node_modules/.bin/electron-rebuild -f -w node-pty
cd ../..
bun run v3:build
bun run v3:start
```

Electronは固定45.0.0。ネイティブPTYはElectronのABI向けにビルドする。設定はアプリ固有のuserData、案件はその下のprojectsが初期値。CLIの認証情報をアプリ設定へコピーしない。既存のV2/API/SQLiteへ接続しない。

1. 「新しい案件を作成」で、このPCの表示された保存先へ案件専用フォルダを作る。または「案件を開く」で既存のフォルダを選ぶ。案件を開くダイアログは現在選択中の案件ルートから始まり、CLI内の一時的なcwdには追従しない。現在のルートが未選択・削除済み・アクセス不能なら、設定済み保存先、書類、ホームのうち利用可能な場所へ順にフォールバックする。キャンセルで案件は変わらない。
2. 設定でCLI版と案件保存先、準備済みハーネスを確認する。
3. 左の「Claude Codeを起動」。フォルダの信頼・ログイン・`/aidlc`などの入力は本人が行う。
4. 実ファイルが安定保存されると右に表示される。HTMLを選ぶと中央で操作できる。文書を選ぶと中央で読む。
5. 修正箇所の指定は実際の操作後画面を撮影する。ピン/矩形と全文を確認し、画像ファイル参照付きの下書きをコピー。本人がCLIへ貼り付けて確認し、送信する。コピーだけでは送信しない。
6. 両境界のハンドルをドラッグ、またはフォーカスして左右キーで幅変更。幅をローカル設定に保存し、ウィンドウ縮小時は中央の領域を確保する。CLIの桁数・行数にも追従する。

新規案件は完了メッセージと保存先を表示し、既存案件を上書きしない。作成中の連打を抑止し、CLI稼働中は本人が終了するまで案件を切り替えない。失敗時は理由を表示して再操作できる。

ローカル成果物一覧は本文やhashを読まず、名前・容量・更新情報だけをページ取得する。1ページ200件、1回の調査800項目、直近8ページまでを保持し、案件全体が64MiB・2000ファイルを超えても閲覧できる。途中・中止・更新あり・除外件数を表示し、「再読取」で先頭へ戻る。列挙中の変更を固定スナップショットとみなさず、選択時に本文を安全に再読取し、実バイトの容量・hash・秘密情報を検証する。本文2MiB超のファイルも一覧には表示するが、開く時に理由を示して拒否する。秘密/隠しパス・symlink・hardlink・パス越境の除外は維持する。

モックの撮影・注釈は、選択HTMLと実際に配信した同一ディレクトリ内の資産、および対応するrough/refined契約と実行対象ポインタの内容・存在を固定する。撮影前後とCLIへの下書きコピー時に実バイトを再照合し、資産や契約の変更は下書きを保持して拒否する。無関係な画像・履歴の変更は撮影を無効にしない。資産は個別2MiB・計16MiB/128件、同時読取4件までに制限する。読込中・読込失敗のモックは撮影できない。共有は別の完全manifestで従来の合計20MiB・個別2MiB・2000ファイルとserver検証を維持する。ローカルで閲覧できても共有可能とは限らない。

動作中に新ビルドへ自動リロードしない。利用者のCLIを終了・案件を保存してからアプリを再起動すると、新しい表示コードが反映される。

## 共同作業

別PCでの共同作業は、管理者が設定したHTTPSサーバーと本人のOIDC/MFA認証を使う。「共同作業」でHTTPS接続先を確認し、案件の招待を入力して本人のブラウザーでログインする。UIから招待/案件選択/編集権/反映/コメント/履歴まで接続済み。詳細な設定と操作は [shared-server.md](shared-server.md) を参照。実IdP/MFA・別の物理PC・実ネットワーク公開は未受入であり、設定/公開は別途承認を要する。

同じPCだけの検証では、独立したloopbackサービスを開始し、一回限りの招待で接続できる。この検証用認証を本番MFAとして扱わない。
共有最新版は一つ。編集を開始した一人だけが変更を反映できる。ほかの人は閲覧・コメントする。サーバーの期限付きリース・epoch・共有版CASが古い編集者の反映を拒否する。接続断/失効はローカルCLIの停止とは別。旧編集フォルダは回復用に保持され、後からの出力を最新版へ勝手に反映しない。「履歴から戻す」は過去版を消さず新しい共有版を作る。

招待は5分、一回限り。セッションは最大4時間（HTTPSはID tokenの期限を超えない）、メモリ上だけに保持されサービス再起動で失効する。資格情報、隠しファイル、個人セッション、監査ログは共有しない。本番のIdP/証明書/サーバー接続先・公開とmembership運用は管理者の設定/受入が必要。

## ハーネス

設定の「公開版一覧・最新版を確認」から、固定した公式取得元の配布版を選び、実行せずに取得する。「プレビュー版も表示」は明示操作で、安定版に見せかけない。配布アーカイブのSHA256、タグのcommit、各ファイルのhashを固定し、取得中のタグ変更を拒否する。既存案件への適用は別の明示操作である。GitHub未認証APIが回数制限の場合も、新たな認証を要求せず、同じ公式公開フィード・チェックサム・匿名Git読取から版を固定する。外部URLやローカルIPへの転送は拒否し、アーカイブのリンク・パス越境・容量超過・破損を拒否する。取得コード/インストーラーの実行はしない。

2026-10-23確認時の公開配布は `v2.11.1-preview.20261016.1` のみ（commit `6a378b53c0a4fe0641ed7d8de8dfff94264d5b6a`）。developの最新ソース `61da68f29914d50c0f962853d04b03df9fa3af9c` とは別である。未公開のdevelopを自動ビルド・実行して最新配布と偽らない。必要なら「ソースの取得／ローカル準備済み配布」から既存のレビュー済み配布を選べる。rootの`.mcp.json`やクラウドMCP設定は取り込まない。

適用前にファイル単位の差分・hashとhook/MCP/権限/実行コードを確認する。長い差分は全文をテキストで開ける。確認対象のplan IDを固定し、古い差分の適用を拒否する。CLI実行中の変更は禁止。既存の利用者設定と管理対象外ファイルを保ち、変更元がずれたら拒否する。直前バックアップへ戻せる。ホーム全体や既存`.claude`全体の上書きはしない。

## 現時点の検証

- Node HTTP実サービス: 20クライアントの認証/案件認可、単一編集権、期限切れ、旧epoch/CAS拒否、全manifest検証、履歴/コメント。
- ローカル: lease別フォルダと失効後の出力隔離、安定hash、秘密/パス/symlink拒否、ハーネス差分・更新・削除・復元・競合保護、プロバイダ環境変数除外。
- 実Electron: 公式CLIの版と対話のフォルダ確認画面。承認やモデル送信は行わない。実動的HTML撮影と画像hash付き下書き、更新後のstale拒否と本文保持、プレビューからNode/IPC/file/外部ネットワークへアクセス不可。
- 表示: 公式Claudeの53→89桁リサイズ、独立した右ペイン、合成PTYで日本語/UTF-8境界/ANSI代替画面と幅の再起動復元。検証用CLIの実PID消滅まで確認。

2つの実Electronでの共有・編集権競合・失効・旧出力隔離・反映・コメント・履歴復元、V2の195 tests / 875 assertions / 22 E2E、lint・型検査・Webビルドが成功。配布用Macアプリの起動・公式CLI版・HTML撮影・再起動復元も成功。詳細は `validation.md`。本人のTeamログインを用いた実モデル応答・実際の画像入力の到達は未検証。過去V2の有料検証をV3成功と読み替えない。


## 工程と原本の表示

画面の種類は右ペインの一つの操作に統一する。中央に別のラフ/詳細セレクターや別HTMLへの移動ボタンは置かず、表示中の画面名・種類と修正指定をコンパクトに表示する。種類変更時は同じ閲覧ラウンドのページ/契約メタデータにある候補を開く。候補がなければ古い別種類の画面を残さず選択待ちにし、本文下書きは保持する。文書表示中の種類変更は文書を切り替えない。取得済みメタデータ以外を全走査して候補を探さない。

「参照・状態／AC」は既定で折りたたむ。閲覧ラウンド、契約の詳細、状態/ACを必要な時だけ展開でき、状態/ACは現在のHTMLに対応する全mappingを保持して表示する。状態は利用者が明示選択するまで未選択で、自動再生・工程承認には使わない。契約未生成・不備は閉じた要約にも残し、撮影不可の理由は外に表示してボタンにも関連付ける。元画像の版・契約/資産hash照合、明示的な下書きコピーと本人送信の境界は維持する。

右ペインは「画面イメージ」と「要件・設計ドキュメント」。画面はラフ案・詳細案・その他に分け、契約の画面名（対応がある場合）または読みやすいファイル名と、区別できるラウンド/パスを表示する。画面の種類・画面名の絞り込みは文書一覧に適用しない。ソース、技能指示、内部ログ、証跡、レビュー資料は通常一覧から除くだけで、原本は削除しない。契約JSON不備でも安全に読めるHTMLは直接選択できる。契約の安全な内容固定ができない場合は閲覧のみとし、撮影・下書き受渡しを許可しない。

`aidlc/spaces/<active-space>/design-document/` と各intentの要件・正式ACは、それぞれ独立したメタデータページで取得する。契約/intent indexの解析失敗や画面ページの位置で統合設計書を隠さない。読取中止・未生成・途中ページ・更新ありを明示し、本文は選択時だけ従来の安全な読取器で検証する。Markdownは見出し・表・箇条書きを整形し、生HTMLと外部画像を実行/取得しない。文書内の相対リンクは案件内の安全な文書/HTML選択へ接続する。128,000文字を超える文書は先頭を整形し、全文を原文でも読める。正式な工程承認や原本更新とは別の閲覧機能である。

V2の既存read-only読取器をそのままビルドに取り込み、実行対象のラウンド/工程と閲覧ラウンドを分ける。Rough/Refinedの契約の解析状態、実バイトhash整合、工程記録を別軸で表示し、schema1は旧形式として扱う。全mapping/ACを保ち、選択だけでHTMLの状態を再現しない。対応するHTMLを明示的に開き、モック内で操作する。過去資料の注釈は引用と明示し、過去工程を自動再開しない。

共有には公開成果物に加えて `aidlc/active-space` と `aidlc/spaces/<space>/intents/active-intent` を含む。隠しエンジン状態・個人セッション・ローカル権限判断は共有しない。編集者の切替で公式CLIが再確認を求めることがある。ローカルのファイル表示や契約一致を正式ゲート承認と解釈しない。

プレビューは選択HTMLのディレクトリ内だけ。別HTMLへのリンク遷移は撮影対象を取り違えないよう拒否し、右の一覧から開く。原本を開くたびに別originとなり、HTMLのlocalStorageを別原本へ持ち越さない。外部通信、file URL、iframe、別ウィンドウ、Node/端末IPCは許可しない。

## 配布と残る本番設定

`node scripts/v3/package-mac.mjs` は現在のソースからmacOS arm64の専用 `.app` を `.cache/v3-mac/` に作る。Electron、コンパイル済みPTY、ハーネス用Bun 1.3.14を含むため、Bun/Python/別Nodeの追加インストールは不要。同梱Bunだけを公式CLIのPATHに追加する。本人の公式Claude CLIと、ソース取得機能にはGitが必要。ローカルad-hoc署名のみで、Developer ID署名/公証/自動更新、Windows/Linux配布は未実施。HTTPS/OIDC/MFA接続機能は実装済みだが、実組織IdPと公開接続先の設定/受入は未実施。AWS構築や共有サービスの外部公開は行っていない。

ハーネス最新ソースの取得は実GitHubで `61da68f29914d50c0f962853d04b03df9fa3af9c` を検証。取得時のスクリプト実行なし、適用済みとは区別した。公開配布の取得から適用まで実装・検証済み。新しい配布の発行基盤/発行者の署名検証/未公開ソースの自動ビルドは含まない。

初回に「Claude Codeを起動」を押すと、案件の作成/選択を案内する。版確認だけを行った状態を編集権失効と表示しない。タイトルと上部にビルドcommitを表示する。
