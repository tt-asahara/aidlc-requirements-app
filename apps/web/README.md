# 日本語 UI 先行デモ

これは **フロントエンドだけで操作を試すデモ** です。実際の AI-DLC、Claude、Bedrock、FakeRunner、API、認証、課金には接続していません。初期会話・設計書・HTML は架空の固定サンプルで、利用者の入力は React のメモリ内だけに保持します。再読み込みでリセットされます。

## 実装順序について

`docs/implementation-plan.md` の通常の M0→M8 順序に対し、今回の明示的な指示に基づき、バックエンド作業と並行して M5/M6/M7 相当の **画面体験のみを先行** しています。M5 の SSE/FakeRunner 接続、M6 の実成果物/ZIP/署名付きプレビュー、M7 のサーバー側許可中継は未完了です。全体の M5/M6/M7 やフェーズ1の完了として扱いません。

作業開始時の最新 `origin/main` は `fc10198`。専用ブランチ `m5-ui-demo` と独立 worktree `/Users/cb-329/work-andy/aidlc-requirements-app-ui` を使用しています。メイン作業ツリーの checkout や既存ファイルは変更していません。

## 起動

リポジトリルートで実行します。API サーバー、AI-DLC の取得、AWS 認証情報は不要です。

```sh
bun install --frozen-lockfile
bun run --cwd apps/web dev --host 127.0.0.1 --port 5274
```

確認済み URL: http://127.0.0.1:5274/ 。Vite の `strictPort` を維持しており、使用中なら既存プロセスを止めずに別ポートを選びます。ルートの `bun run dev` はバックエンドも起動するため、この UI デモ単独確認では使いません。

## 操作

- 左上の「プロジェクト一覧」からサンプルを切り替え、新しいプロジェクトを作成できます。新規プロジェクトには会話・成果物の空状態があります。
- 初期サンプルには模擬許可カードがあります。「許可」は未送信の下書きだけを作り、「拒否」は要求を終了します。許可後の「許可を取り消す」で取り消せます。手入力で変更済みの下書きは保持します。どの操作もコマンドを実行しません。
- 回答欄または選択肢で模擬送信します。自由文と「内容を見直す」は進捗を進めません。「この内容で次へ」だけが次の模擬ステージに進みます。回答入力は最大20,000文字です。
- 1プロジェクトの模擬実行は同時に1つだけです。約1.8秒の実行中は送信と許可操作を無効化し、「中止」で止めます。中止後の遅延結果や重複した完了イベントは無視します。
- 「デモの操作を試す」から許可カードの追加、次の送信でのエラーを試せます。エラーからの再送は利用者が明示的に押したときだけ行います。
- 7つの模擬ステージを確認すると次の要件ラウンドを開始できます。履歴から過去のラウンドを見ても、未完了ラウンドが残っている場合は新規開始を抑止します。
- 右側の設計書・ファイル・HTML モックを切り替えられます。会話内の成果物パスもファイル選択に連動します。「設計書を更新」は架空の表示版だけを更新します。
- HTML モックの予約ボタンは iframe 内のテキストだけを変更します。実注文・決済は行いません。ランチ以外のプロジェクトでは共通参考例であることを表示します。
- ペイン境界はドラッグ、またはフォーカス後の左右キーで可変幅にできます。タブは左右キー・Home・End、入力は ⌘/Ctrl+Enter、ダイアログは Escape に対応します。日本語 IME 変換中の送信を抑止します。
- 900px 以下では進捗＋会話/成果物の2列、600px 以下では縦積みです。320px 幅から利用可能で、デモの注意書きはスクロール時も上部に固定します。

## 後で接続する境界

| 現在 | 今後の接続先（計画10章） |
| --- | --- |
| `demo/model.ts` のプロジェクトとラウンド | `GET/POST /api/projects`、progress 読み取りと `start_round` action |
| `send` → タイマー → `finish` | `POST /turns` と SSE。サーバー応答を正本にし、ローカルで進捗を推定しない |
| `cancel` と job ID による遅延結果の排除 | `/turns/:turnId/cancel` とサーバー側の終了状態 |
| 模擬許可、拒否、取消、下書き | `/permissions`、approve/deny/revoke。本人・時刻・完全一致ルールはサーバーが検証・保存 |
| `demo/artifacts.ts` の固定サンプルと `DocumentView` | 読み取り API、Markdown/GFM 表示、実成果物の種類・カバレッジ |
| 固定 `srcDoc` の HTML | `/preview-token` → `/raw/:token/<path>`。相対資源・Cookie 隔離の E2E は接続時に実装 |
| 費用なしの表示 | 実際の費用差分、予算超過、タイムアウト、再接続状態 |
| 未実装の ZIP・全再生成・要件再開 | 実 API の実装後に明示的な利用者操作として追加 |

`demoReducer` の action は **SendTurn API の型ではありません**。番号抽出や固定プロンプトへの変換を代行せず、実モデルへの接続機能も持ちません。API 接続時は `packages/shared` の型とサーバーの `prompts/` を使用してください。既存 `src/api/health.ts` は残していますが、このデモ画面からは呼びません。

HTML は開発者が書いた定数だけを `srcDoc` に渡し、利用者入力は React のテキストとしてエスケープ表示します。iframe の `sandbox="allow-scripts"` に `allow-same-origin` は付けません。CSP は `default-src 'none'`、外部通信・フォーム送信・base 変更を禁止し、固定のインライン CSS とローカル操作スクリプトだけを許します。実ファイルプレビュー時にはサーバーの CSP と署名付きルートが別途必要です。
